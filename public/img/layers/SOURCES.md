# Neekah layer artwork — sources & licences

Every file in this folder is **original artwork generated procedurally** by
`database/seeders/assets/generate_layer_assets.py` (florals, arches, frames, Islamic geometry,
songket / tenun / pucuk-rebung patterns, dividers, textures, tape, wax seal, film holes, photo placeholders).
No third-party images, PNGs or textures are bundled, so there is nothing to attribute:
the artwork is released for unrestricted commercial use by Neekah (CC0).

Most files are single-colour alpha masks. The renderer tints them with the layer's colour / gradient
(`ornament` layers, see `resources/views/components/invitation/layer.blade.php`), which is how one asset
becomes gold, rose, emerald or bronze in different templates.

`photo-*.svg` are demo placeholders. They show in the editor and template previews only, never on
a customer's public invitation.

## Replacing the demo artwork with licensed premium assets

1. Add the licensed file (SVG recommended; PNG / WebP / JPG also allowed) under `public/img/layers/`
   with a lowercase name (`[a-z0-9_-]`), e.g. `public/img/layers/premium/floral-01.svg`.
2. In the template's layers change `src` to `/img/layers/premium/floral-01.svg`
   (edit through Admin → Templates → Edit layers, or in `app/Services/Invitation/Marketplace/*`).
3. Record the source and licence in the table below.

| File | Source | Licence |
| --- | --- | --- |
| all `*.svg` above | Generated by `generate_layer_assets.py` | CC0 / original |

Preferred sources for future premium assets: Unsplash, Pexels, Pixabay, Wikimedia Commons (public-domain
or CC0 items only), or assets purchased with a commercial licence. Do not use images from Pinterest,
TikTok or Instagram.
